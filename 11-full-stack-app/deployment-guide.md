# Chapter 11: Deployment Guide
## Business Management System

### Step 1: Open Apps Script

1. Open a Google Sheet
2. Click **Extensions > Apps Script**
3. Name your project "Business Management System"
4. Delete placeholder code

### Step 2: Add the Backend Code

1. Copy `Code.gs` into the `Code.gs` file
2. Click **Save**

### Step 3: Add the HTML File

1. Click **+** next to "Files"
2. Select **HTML**
3. Name it `BusinessManagement`
4. Copy `BusinessManagement.html` into it
5. Click **Save**

### Step 4: Deploy

1. Click **Deploy > New deployment**
2. Select **Web app**
3. **Execute as:** Me
4. **Who has access:** Anyone
5. Click **Deploy**
6. Copy the URL

### Step 5: Test

1. Open the URL
2. Click **Sample Data**
3. Explore all tabs!
