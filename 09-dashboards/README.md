# Chapter 9: Dynamic Dashboards with Charts

| File | Description |
|------|-------------|

| `sample-data.csv` | Sample sales data for testing |
| `deployment-guide.md` | Step-by-step deployment instructions |

## 📝 What You'll Build

An executive dashboard that:
- Shows KPI cards (total sales, average, growth, etc.)
- Displays sales trends over time
- Visualizes sales by region, product, and representative
- Provides interactive filters
- Auto-refreshes every 5 minutes

## 🚀 Quick Start

1. Copy `Code.gs` into your Apps Script project
2. Create a new HTML file named `ExecutiveDashboard.html`
3. Deploy as a web app
4. Add sample data or import your own
5. View your dashboard!

## 📊 Charts Used

| Chart | What It Shows |
|-------|---------------|
| **Line Chart** | Sales trend over time |
| **Pie Chart** | Sales by region and product |
| **Bar Chart** | Sales by representative |
