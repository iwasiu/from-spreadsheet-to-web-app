# Chapter 3: Deployment Guide

## Adding Validation to Your Web App

### Step 1: Update Your Code

1. Open your existing Apps Script project
2. Replace `Code.gs` with the updated version from this folder
3. Replace `Index.html` with the updated version from this folder

### Step 2: Test Validation

1. Open your web app URL
2. Paste messy data (including "N/A", "$1,550", "1,300")
3. Click **Analyze Sales**
4. Verify that validation errors are shown

### Step 3: Re-deploy (Optional)

If you want the latest changes:

1. Click **Deploy > New deployment**
2. Select **New version**
3. Click **Deploy**
