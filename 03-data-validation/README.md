# Chapter 3: The Art of Data Validation

## 📁 What's in This Folder?

| File | Description |
|------|-------------|
| `Code.gs` | Backend Apps Script with validation |
| `Index.html` | Frontend with validation logic |
| `sample-data.csv` | Sample data (includes messy entries for testing) |

## 📝 What You'll Build

A data validation layer for your Sales Analyzer that:
- Removes formatting (commas, dollar signs)
- Rejects non-numeric values
- Applies business rules (positive values, ranges)
- Shows helpful error messages

## 🚀 Quick Start

1. Replace your existing `Code.gs` with the one in this folder
2. Replace your existing `Index.html` with the one in this folder
3. Re-deploy your web app
4. Test with messy data

## 📚 Related Chapter Content

This code accompanies **Chapter 3: The Art of Data Validation** of the book *From Spreadsheet to Web App*.

The chapter explains:
- Why validation matters for business trust
- How to clean messy data automatically
- How to apply business rules (logic and comparisons)
- How to show user-friendly error messages
