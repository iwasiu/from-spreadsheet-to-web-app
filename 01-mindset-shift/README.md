## 📝 How to Use This Code

1. Open a Google Sheet
2. Go to **Extensions > Apps Script**
3. Delete the placeholder code
4. Copy and paste the contents of `analyze-sales.gs`
5. Save the project
6. Back in your sheet, type `=analyzeSales(B2:B21)`
