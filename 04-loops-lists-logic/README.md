| File | Description |

| `sample-data.csv` | Sample customer data |

## 📝 What You'll Build

A bulk email sender that:
- Reads customer data from Google Sheets
- Processes each customer using loops
- Generates personalized email content
- Sends emails automatically via Gmail

## 🚀 Quick Start

1. Copy `Code.gs` into your Apps Script project
2. Create a new HTML file named `EmailSender.html` and copy the HTML code
3. Deploy as a web app
4. Add sample data to your sheet
5. Test the email sender

## 📚 Related Chapter Content

This code accompanies **Chapter 4: Loops, Lists, and Logic** of the book *From Spreadsheet to Web App*.

The chapter explains:
- Different types of loops (forEach, map, filter, reduce)
- How to process large datasets efficiently
- Set theory concepts (union, intersection, filtering)
- Business logic for email personalization
