| File | Description |
|------|-------------|
| `Code.gs` | Backend report generation logic |

## 📝 What You'll Build

A report generator that:
- Reads data from Google Sheets
- Generates professional HTML reports
- Converts HTML to PDF
- Emails reports to stakeholders
- Saves reports to Google Drive

## 🚀 Quick Start

1. Copy `Code.gs` into your Apps Script project
2. Create a new HTML file named `ReportGenerator.html`
3. Deploy as a web app
4. Add sample data or import your own
5. Generate your first report!

## 📊 Report Features

- **Summary Cards:** Total sales, quantity, average, transactions
- **Top Performers:** Best product, category, region
- **Breakdown Tables:** By product, category, region
- **Transaction List:** Recent transactions
- **Professional Formatting:** Clean, branded design
