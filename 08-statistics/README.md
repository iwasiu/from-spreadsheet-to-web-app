## 📝 What You'll Build

A customer satisfaction analyzer that:
- Calculates mean, median, mode, variance, and standard deviation
- Identifies outliers using Z-scores
- Shows distribution with visual bars
- Provides confidence intervals and percentiles
- Displays top and bottom comments

## 📊 The Statistics You'll Use

| Concept | What It Does |
|---------|--------------|
| **Mean** | Average score |
| **Median** | Middle value |
| **Mode** | Most common value |
| **Standard Deviation** | How spread out the data is |
| **Z-Score** | How many std devs from mean |
| **Confidence Interval** | Range where true mean lies |
| **Percentiles** | Distribution of data |

## 🚀 Quick Start

1. Copy `Code.gs` into your Apps Script project
2. Create a new HTML file named `SatisfactionAnalyzer.html`
3. Deploy as a web app
4. Add sample data or import your own
5. Analyze your customer satisfaction!
