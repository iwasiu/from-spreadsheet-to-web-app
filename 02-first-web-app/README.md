| `sample-data.csv` | Sample sales data for testing |
| `deployment-guide.md` | Step-by-step deployment instructions |

## 📝 What You'll Build

A fully functional web application that:
- Accepts a list of sales numbers
- Calculates total, average, and standard deviation
- Flags outliers (values more than 2 standard deviations from the mean)
- Displays results in a clean, professional interface

## 🚀 Quick Start

1. Copy `Code.gs` and `Index.html` into Google Apps Script
2. Follow `deployment-guide.md` to deploy
3. Share your URL with your team
